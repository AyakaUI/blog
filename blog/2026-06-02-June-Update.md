# What's new?

### We are happy to announce a new package, DroidSpaces!
Droidspaces is a lightweight, portable Linux containerization tool that lets you run full Linux environments on top of Android, Linux, or even in minimal environments like Android recovery/Ramdisks, with complete init system support including systemd, OpenRC, and other init systems (runit, s6, etc.). You can read more [here](https://github.com/ravindu644/Droidspaces-OSS)!
